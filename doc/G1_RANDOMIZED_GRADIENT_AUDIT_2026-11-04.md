# G1 配对梯度检验、完整 actor 更新与当前课程

## 问题、假设与结论

3000 轮新隐式 PD 模型主要稳定站立，仍未迈步。旧首动作检验的物理分支并非完全相同，且正负方向固定在场景位置，不能据模型与真实收益差异直接判断梯度无效。

本轮完成两种随机分支检验，各使用 1701 / 2026 两个种子：

1. 128 组 × 14 分支，统一动作接触预热，随机分配正负首动作扰动及两个零对照；增加较小扰动和成对置信区间，观察 128 步真实仿真。
2. 256 组 × 6 分支，恢复 checkpoint 的 Adam 动量、3001 轮实际学习率和梯度裁剪，只对临时 actor 做一次更新，再在每步应用该参数变化的 ±1 / ±0.25 倍；世界模型、critic、D、观测归一化及正式 checkpoint 均不改变。

小幅首动作扰动和完整临时 Adam 更新均可提高普通起点的真实累计奖励。不能再把下一步建立在“梯度完全无效”或“完整 actor 更新必然损害真实回报”的假设上。模型仍高估普通状态的短期收益幅度，参考动态状态的稳定性也很差；这些结论没有证明行走改善或全部梯度可靠，也不支持优先更换隐式 PD。

## 方法依据与实现

核对 Isaac Lab 2.1 的[可复现性说明](https://github.com/isaac-sim/IsaacLab/blob/v2.1.0/docs/source/features/reproducibility.rst)：相同种子有助于跨运行复现，但不能将“不同场景位置的可见状态相同”当作完全相同的接触内部状态。GitHub 查询还返回了其他版本 / 求解器相关结果，未移植不适用的修复。检索原文保留于 `logs/amp_g1/paired_audit_github.json`。

更新 `scripts/g1_return_direction_audit.py`：

- 接触预热各克隆共用动作，随机分配干预角色，记录状态 / 观测 / 前动作 / 指令 / gait / AMP 历史的配对误差。
- 分别报告累计物理奖励和含 critic 尾项的回报；32 步以后只测真实物理后果，不继续外推 WM。
- 以完整克隆组为单位做 2048 次 bootstrap，给出均值的 95% 区间；用两个零干预分支检查配对噪声。
- 参数更新模式恢复原 Adam，学习率 `2.92874014e-5`、betas `.9/.95`、`grad_clip=1`。只做临时候选 actor 单步诊断，不保存候选 checkpoint。
- 输出路径存在时拒绝覆盖；保留命令、PID、工具 SHA256 和原始 JSON。

## 首动作结果

普通起点、全关节正向 RMS 0.03，128 步折扣物理奖励相对两个零对照均值的增益：

| 种子 | 增益均值 | 成对 95% bootstrap 区间 |
| --- | ---: | --- |
| 1701 | +.01056 | [.00369, .02144] |
| 2026 | +.00500 | [.00426, .00575] |

参考起点相同设置的两组区间均跨 0。此前仅凭单样本零对照 RMS 接近平均收益，无法判断均值是否可区分；本轮增加样本及成对区间后，普通起点获得了更明确的局部正收益证据。

## 完整 actor 单步结果

完整临时 Adam 正向一步、128 步折扣物理奖励的增益：

| 起点 | 种子 | 增益均值 | 成对 95% bootstrap 区间 |
| --- | --- | ---: | --- |
| 普通 | 1701 | +.00784 | [.00721, .00848] |
| 普通 | 2026 | +.00742 | [.00676, .00806] |
| 参考 | 1701 | +.00548 | [.00038, .01287] |
| 参考 | 2026 | +.00496 | [.00038, .01029] |

普通起点的反向一步分别为 -.00778 / -.00999；正向四分之一步约 +.00215 / +.00206。完整一步在种子 1701 / 2026 的种子动作 RMS 变化约 .00455 / .00444，符合小幅策略参数更新的量级。

普通起点 H32 的模型 bootstrap 改进约 .0703 / .0656，真实约 .00763 / .00709，幅度仍偏大。参考起点 128 步原生存活率仅 30.9% / 23.0%；短时奖励增加不能代替持续步行。

## 当前实际速度课程与 AMP 引入

本节核对当前正式 run 的 `config.json`、`g1.walk_task`、`Trainer.run/set_training_rewards`，不是下一轮建议：

- 速度范围从训练开始固定：vx=[0,1.2] m/s，vy=[-.3,.3] m/s，yaw=[-.8,.8] rad/s；没有逐渐扩大速度范围的课程。
- 指令每 6–10 秒重采样，普通采样约 10% 站立；50% reset 使用训练参考帧，首次命令与该帧速度对齐，因此实际 reset 命令分布不是单纯的全范围均匀分布。
- 1–300 轮只预热 WM；301–500 加入 critic；D 首次在 305 轮更新，以后每 5 轮更新 2 步；actor 从 501 轮开始更新，其学习率系数在 1000 轮达到完整值。
- `w=.5*min(iteration/1000,1)`；混合为 `(1-w)*R_task + 2*w*dt*R_style`。500 轮为 `.75*task+.5*dt*style`，1000 轮起为 `.5*task+dt*style`。
- 16 项任务奖励从开始采用最终配置。`reward_curriculum_start/end=0/0`；而且该上游奖励类型在 `training_task` 中直接保留权重，不能只打开旧课程 CLI 就认为已启用渐进奖励。
- 本轮是全新隐式 PD 的随机初始化，先预热模型 / critic 再直接优化 AMP；历史 DC 速度冷启动没有用于初始化当前模型。

## 边界、后续优先级与证据

配对状态和历史仍有接触数值差异，置信区间以当前 reset 分布为条件，未做多重比较校正。临时 Adam 用的是本次起点批次，不能等同生产 replay 的全部分布；WM、D、critic 和归一化在诊断中冻结，也没有复现四网络持续交互。因此不把本轮解释为全部训练接口 / 分布已排除，更不能解释为 G1 已收敛。

下一步不重复当前梯度方向检验，也不据此盲续长训或换 PD。优先核对参考动态状态的训练覆盖 / 存活，以及相对上游仍存在的 D 实现和样本预算差异：当前 D512/256 LeakyReLU、专家与策略共同归一化、统一 decay；上游 D1024/512 ELU、策略样本更新归一化、输出层独立 decay。更新 interval 的计数单位和每个物理样本参与的 D 更新预算也须核对，不能只因都写 interval=5 就当作相同。形成可验证假设后再选择独立修复，不做奖励权重网格。
