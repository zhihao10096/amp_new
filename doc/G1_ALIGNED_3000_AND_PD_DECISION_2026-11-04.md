# G1 对齐基线 3000 轮评估与 PD 选择

## 结论

G1 已使用上游 legged_lab 的隐式 PD 和固定力矩上限，不含 DC 模型的转速降额。用户允许的 Isaac Lab IdealPD 也是合适的候选：显式计算 PD 力矩，再按固定上限裁剪。目前没有证据表明隐式 PD 有缺陷，暂不切换动力学。

同配置从 1000 续到 3000 轮后，策略从频繁失稳变成主要稳定站立，仍未学会迈步。2000、3000 两点完整速度及步态评估均失败；没有已通过验收的 G1 最佳模型。不能把低风格距离、较少摔倒或接口通过解释为行走收敛。

## 问题、假设与方法

1000 轮包含 300 轮世界模型和 200 轮 critic 预热，actor 实际只更新 500 次。为检验是否只是训练不足，固定执行器、奖励、AMP、RSI、网络、探索和学习率日程，从 1000 恢复四网络及四优化器，使用 `--continue-run` 续到 3000；不重新预热，不导入历史 DC 世界模型。

## 冻结世界模型与回报方向检验

3000 冻结模型审计中，普通 / 参考起点的 32 步真实与想象 bootstrap 均值分别为 `3.297 / 2.297`、`.826 / .318`；线速度开环 RMSE 为 `.117 / .262`，actor 梯度有限且 norm 为 `170.97 / 29.26`。冻结起点、是否经过接触预热会改变分布；不能把这组数值与下一项配对实验直接拼成同一受控对照。

另做 32 个起点 × 10 分支、8 步共同接触预热的首动作方向检验。方向取 32 步想象回报对首动作的梯度，按动作 RMS 归一化；只在第一步施加全关节或腿部 `±0.1 / ±0.3` 扰动，后续各分支使用同一冻结 actor 闭环。含两个无扰动对照，不训练、不做 MPC。

32 步、全关节 RMS 0.1 的结果：

| 指标 | 普通起点 | 参考起点 |
| --- | ---: | ---: |
| 真实中央差分回报斜率均值 | .2311 | .1315 |
| 模型中央差分回报斜率均值 | 2.7514 | .3354 |
| 真实正斜率样本比例 | 100% | 71.9% |
| 跨样本真实 / 模型斜率向量余弦 | .7322 | .1399 |
| 正扰动相对无扰动对照的回报增益均值 | +.00106 | -.00164 |
| 两个无扰动对照的回报差 RMS | .00294 | .00597 |
| 预热后两个无扰动分支的状态差 RMS | .01070 | .07355 |

模型对普通起点的首动作收益幅度高估约 12 倍；参考起点的样本间一致性较弱。但多数正方向只是比负方向好，正方向相对零对照的平均收益很小或为负。

这些结果提示模型、critic 和局部优化信号需要继续核查，尚不能确认其为起步失败根因：

- 克隆可见状态并共同预热后，PhysX 接触状态和控制历史仍未保证逐分支一致。
- 当前分支位置固定，未随机交换正负方向，也未报告成对置信区间。
- 零对照的单样本 RMS 与小扰动收益接近；尚未对“平均收益是否显著”做统计检验。
- JSON 中 `direction_cosine` 是跨样本标量斜率向量的余弦，不是完整动作空间梯度的夹角。
- Bootstrap 共用同一 critic，不能作为无偏真实长回合回报；首动作方向也不等于整张策略网络的更新方向。

因此既不能说“梯度完全错误”，也不能说“梯度已验证正确”。

## PD 决定与下一步

Isaac Lab 隐式 PD 将位置目标交给 PhysX 在积分中求解；IdealPD 在物理子步显式计算 `Kp*(q_target-q) + Kd*(qd_target-qd) + tau_ff`，再固定限矩。两者均可满足不用 DC 转速降额的要求。IdealPD 的显式公式方便核对，但不因此保证比上游隐式 PD 更好。

当前保留已验证接口的上游隐式 PD，不新增奖励权重网格，不盲续同配置。下一步先复核配对实验：统一控制历史、随机交换分支、记录动作与观测配对误差、增加零对照和成对置信区间，并区分累计物理奖励与 critic 尾项；形成可验证假设后再按项目规则检索适用的公开实现。

若后续证据支持 IdealPD 对照，单独使用新的执行器类型和世界模型谱系，保持增益、动作映射及固定限矩一致，完成 CPU / 真实 GPU / 想象梯度 / 保存恢复验证；不直接恢复隐式 PD 或历史 DC 世界模型，不把切换控制与其他改动叠加。
