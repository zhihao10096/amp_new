# G1 AMP 与 Go2、A1、legged_lab 的实现对照

核对基线：本项目 `8f63846`，干净的 `reference/legged_lab` 固定于 `f33a18904e5209d9aceb95ef78ed82412c5f2072`。上游判别器和奖励配置的 GitHub 固定版本已与本地 SHA256 核对。本文记录源码及实际 checkpoint 证据，不把差异本身当作小碎步的因果证明。

## 已验证的偏差

| 路径 | legged_lab G1 | 本项目历史 G1 | 影响与处理 |
|---|---|---|---|
| 关节驱动 | PhysX 隐式 PD，固定分组力矩上限 | 显式 DC PD，转速相关力矩包络 | 改变动力学。用户明确去掉 DC，当前恢复隐式 PD；实现/验证见 `G1_IMPLICIT_PD_RESTORE_2026-11-04.md`。 |
| AMP 与任务组合 | `0.5 * task + 0.5 * (2 * dt * style)` | `task + 0.5 * dt * style`，另有 ramp | 假定任务奖励相同且 ramp 完成，上游 style/task 系数比为 2，本项目为 0.5，相差 4 倍；不能只比较参数名中的 0.5。 |
| AMP 站立门控 | style 不按速度命令清零 | 命令范数≤0.1 时 style=0 | 同一 D score=1，原始 style 在 stand/walk 下为上游 1/1、本项目 0/1；已执行上游原方法验证。 |
| 默认姿态偏移惩罚 | 仅髋 yaw/roll、手臂、腰，且仅平移命令范数<0.06时生效 | 全 29DOF L1，运动时也惩罚，站立再乘 5 | 额外限制髋 pitch 和膝关节步行偏移。0.6m/s命令下髋 pitch=.3、膝=.4rad时，历史每秒贡献=-.021，上游=0。 |
| 力矩/加速度/位置限位惩罚范围 | 分别仅腿部、髋膝、脚踝 | 均覆盖全部 29DOF | 权重数值相近也不代表同一目标；需同时对齐关节集合。 |
| 速度跟踪 | 平移用 yaw 坐标系，yaw rate 用世界 z；权重1/2 | 平移及 yaw rate 用完整机体系；权重1.5/1 | 倾斜时公式不同，需针对坐标转换做数值对照。 |
| 其他任务项 | 16项，termination=-200 | termination=-50，另加高度、能量、足净空、接触、步态时长、flight、脚间距等项 | 当前不是“直接使用已验证上游奖励”的实现；先做一致性修复，停止盲目权重网格。 |
| RSI 与命令 | 同参考帧重置，并对齐机体系命令 | 参考状态与随机命令独立 | 双方机器人均有命令冲突，不能单独解释G1；上游命令计数逻辑不能直接复制到本机Lab2.1。 |

AMP 混合、16项配置及姿态门控反例由只读脚本执行上游原方法得到，报告 `logs/amp_g1/go2_a1_g1_legged_lab_source_audit.json`。该报告的 DC 力矩例子描述 **修复前的 8f63846**，不能重跑后覆盖为“当前仍使用 DC”的证据。新增 AMP 门控验证为 `logs/amp_g1/upstream_amp_command_gate_probe.json`。

## Go2 / A1 对照能说明什么

实际 checkpoint 已核对：Go2 是随机初始化谱系，并使用基础速度到最终步态奖励的课程；A1 是继承已收敛 Go2 actor/世界模型的 12DOF 热启动。G1 直接随机 AMP 失败后，复现 Go2 冷启动流程到9000已能稳定移动，但仍为高频碎步；后续无AMP、61/64/70维及四帧诊断未通过 walk。

A1/G1 同1m/s评估的摆动时间约 .175/.093s、净空20.77/12.36mm；A1奖励中的时长惩罚更强，判别器训练强度也不同。这证明学习结果和训练路径不等价，不能推出“加强某一个权重就能解决G1”。详细物理指标与独立CPU反事实见 `A1_G1_SMALL_STEP_COMPARISON_2026-11-04.md`。

## 保留的任务边界与下一步

用户要求的平地、walk、最高前进命令1.2m/s及禁PPO继续有效。上游较宽的0–3m/s范围不直接复制为本项目目标；参考动作继续使用项目内Git追踪副本，X1仍在G1独立成功后开始。

本轮先完成隐式PD修复及独立验证，旧DC世界模型不直接复用；用户允许IdealPD备选，但没有证据说明隐式PD不好。之后按已验证的上游公式、关节范围和AMP混合补齐明确的G1奖励配置，先用数值 oracle 与真实GPU验证，再建立新控制下的训练基线。不上权重网格，不混用旧DC checkpoint 的收益结论，不把源码对齐或短跑视作行走收敛。

当前 G1 AMP 尚未成功；已确认实现偏差，尚未证明其中哪项是碎步根因。
