## 结论与证据强度

已证实的失败模式是G1形成站立策略，风格改善未带来行走。A1热启动解释了它的快速达标，但Go2确实从零成功，因此不能用热启动解释全部差距。当前最有依据的机制假设是：G1缺乏有效的步态启动课程，风格和部分步态奖励允许静止替代，动态闭环数据与价值学习又不足以跨出站立状态。各因素对最终失败的因果贡献尚未由单因素闭环消融分离。

Go2最终9000 checkpoint的 `training_origin.kind=random_initialization`，seed0；后续resume均沿其自身谱系，未加载外部策略、未使用PPO。随机初始路径及逐项审计见 `MANAGER_CONVERGENCE.md`。不能把三轮独立G1的3000相加，称同一策略已训练9000。

Go2早期曾遇静止解；修复初期惩罚公式后才得到可行速度基线（`MANAGER_BASELINE.md`）。其初期关节项为 `-.05*sum(q_offset²)`；G1始终 `-.03*sum(abs(q_offset))`。运动指令下每关节偏移.01rad时，G1该项代价为Go2初期的60倍、非零点梯度幅度为30倍，均在乘相同dt之前。这是局部项的确切差异，不等于总奖励或actor梯度相差这些倍数。G1的reward没有读取 `joint_deviation_gait_fraction`；单独打开现有课程CLI不能还原Go2的初期平方公式。G1权重整体较弱也不能替代对公式和启动阶段的检查。

## 2. G1的AMP不能充分排斥静止替代

A1每帧43维特征包含线速度、局部足端位置及根高度；G1每帧61维只含角速度、29关节角、29关节速度。CPU探针对同一G1状态只改变线速度、高度、重力方向、足端位置和接触，特征与D分数差严格为0。该检查证明直接可辨识性缺失，不是说这些变量在物理轨迹中与关节完全独立，也不表示任务奖励不看速度。

冻结正式R3的D，对8192组训练参考特征做离线反事实检查：

| 输入 | 平均style |
| --- | ---: |
| 正常相邻专家对 | .89035 |
| 复制首帧但保留速度通道 | .89008 |
| 首尾交换但保留速度通道 | .88873 |
| 随机打乱第二帧 | .84763 |
| 同一姿态重复、角速度和关节速度清零 | .87366 |

这些是特征探针，不能当作真实稳定站立轨迹；它们显示当前D对局部时序/运动停止的惩罚较弱。与既有真实证据一致：R1静态参考关节目标控制在2秒内128/128摔倒，却有style约1（`reference_behavior_diagnostic_r2.json`，名称r2指诊断版本，模型来自正式R1）。R3完整评估风格距离改善59.2%/59.0%，0.6m/s实际vx约.000027、步频0。

当前D仅两帧，跨度20ms；固定参考legged_lab配置四帧。增加历史或速度特征仍须独立闭环验证，不应称为已解决。AMP作者的 [MimicKit实现](https://github.com/xbpeng/MimicKit/blob/main/mimickit/envs/amp_env.py)提供根速度、关键体位置等观测接口，可用于核对设计；不直接移植其学习算法。

## 3. 当前奖励缺少可靠的起步引导

生产 `g1.reward` 的离地项为：足高误差乘 `tanh(2*足端水平速度)`，再取负指数。脚水平速度为0时，任何足高都得到该项最大值1；权重.15对应每秒+.15，足高方向梯度为0。CPU直接调用生产函数验证通过。因此这一项约束已在摆动的脚，不能单靠它诱导第一次抬脚。A1/Go2也使用类似公式，区别在于Go2早期关掉此项，A1已有行走能力；不能把它表述为G1独有错误。

R3既有真实策略轨迹的普通reset前32步：平均vx=.00203m/s，总奖励折合1.372/s，yaw跟踪贡献+.963/s、离地+.142/s、AMP+.210/s。此时无摔倒；它说明不前进也能获得若干正项，并不能证明站立总回报高于一个成功步行策略。参考RSI前32步总奖励1.379/s，随后存活明显下降；需联合后续风险与价值尾项理解，不能把不同初态当作受控策略对照。

## 4. 当前移植与SuperMimic原任务存在关键差异

[SuperMimic原论文](https://arxiv.org/pdf/2610.28480) §3、附录A/B：运动接口输入未来10帧参考目标，使用身体/根部位置、朝向、速度的跟踪奖励；速度接口共享运动解码器，速度目标只更新其编码器，解码器由运动跟踪训练。当前项目保留WM可微想象更新路线，但G1 actor只有自身历史和速度指令，没有参考相位/未来目标接口，AMP提供分布级风格奖励。

因此本项目的G1冷启动并非原论文完整运动跟踪任务复现。用其速度或收敛时间直接保证当前任务会快速收敛并无依据。一个可检验的后续方向是仍通过WM训练的参考目标/相位辅助课程，然后验证独立速度行走；这不是调用外部PPO策略或逐帧强写PhysX状态，当前尚未实现。

## 5. 动态学习、参考覆盖及reset条件

双足重心转移和单支撑要求可能放大从静止起步的探索困难；这里是机制解释，不是本项目的单因素证明。已有动态拟合/响应约束使8步速度RMSE .0767→.0317，但统一预热后的真实MPC仍16/16摔倒。普通32步真实/想象bootstrap回报3.038/3.089接近，参考RSI为1.123/.866；不能简单归因于“模型整体爆炸”或“想象过度乐观”。完整限制见 `G1_DYNAMICS_RESPONSE_2026-11-04.md`。

按当前权重抽32768个训练参考：平面速度<.1m/s占22.83%，vx<-.1占13.41%；vx>.25且|vy|<.15、|yaw|<.3的直行窗口占8.09%。这是混合转弯/侧移/倒走数据，并非纯稳定前向步行，但其中有43.02% vx>.25，不能称数据完全没有前走。瞬时比例也不是连续有效步态比例。

固定参考legged_lab的 `mdp/commands/velocity_command.py` 会在参考reset时对齐同帧速度指令，当前 `BodyVelocityCommand` 独立随机采样。CPU独立采样显示55.09%参考初态与指令的平面速度差>.5m/s；这是分布推算，尚非实际reset遥测或闭环因果证据。该差异应作为成本较低的独立消融候选，避免与奖励/特征同时修改。
